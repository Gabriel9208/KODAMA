KEY ADDITIONS
=============

semantic_decoder.py Architecture:
  Class: UpsampleBlock
    - Learnable: Conv2d(in, out, 3×3) + GroupNorm + ReLU
    - Fixed: Upsample(scale_factor=2, bilinear)

  Class: SementicDecoder
    - Input: P3 (80×60, 64ch), P4 (40×30, 128ch), P5 (20×15, 256ch)
    - P3 pathway: Conv only (keeps spatial dims)
    - P4 pathway: 1× UpsampleBlock → 80×60
    - P5 pathway: 2× UpsampleBlock → 80×60
    - Fusion: Element-wise addition
    - Output head: Conv(1×1) to num_classes, then 8× Upsample
    - Final output: (batch, num_classes, 640, 480)

Model Training Flow (NEW):
  1. Load YOLO backbone (frozen weights)
  2. Register feature hooks on layers 16, 19, 22
  3. Initialize SementicDecoder with channels (64, 128, 256)
  4. For each training batch:
     a. Extract P3, P4, P5 via FeatureExtractor hooks
     b. Pass to SementicDecoder → semantic logits
     c. Compute loss vs ground truth masks
     d. Backprop only through decoder (YOLO frozen)
  5. (Future) Panoptic fusion layer combines instance + semantic
